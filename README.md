# NetProg

Клиенты сетевых служб daytime (RFC 867, UDP) и echo (RFC 862, TCP).

## Сборка

```
cd daytime && make
cd echo && make
```

`make clean` удаляет объектные и исполняемые файлы.

## Запуск

```
./daytime_client -s <сервер> [-p <порт>] [-t <секунды>]
./echo_client -s <сервер> [-p <порт>] [-t <секунды>] <сообщение>...
```

Порт по умолчанию: 13 для daytime, 7 для echo. Таймаут ожидания ответа
по умолчанию 5 секунд. Справка: `-h` или запуск без параметров.

## Пример

```
$ ./echo_client -s 127.0.0.1 hello
Соединение с 127.0.0.1:7 установлено
> hello
< hello
Совпало 1 из 1
```
